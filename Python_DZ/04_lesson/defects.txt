Заголовок:
    Ошибка в функции parametrize, функция принимает в работу не корректные данные.

Описание:
    Функция parametrize принимает в обработку пустую строчку, строчку только из пробелов,
    и строчку которая начинается с цифр.
    Когда по логике функции не должна этого делать.

Шаги для воспроизведения:
    1. Вызвать функцию parametrize с аргументами: input_str="123abc".
    2. Вызвать функцию parametrize с аргументами: input_str="".
    3. Вызвать функцию parametrize с аргументами: input_str="   ".

Ожидаемое поведение:
    Функция должна делать первую букву заглавной. По скольку цифра,
    пробел и пустая строчка не явлется буквой,
    функция не должна ее принимать.

Фактическое поведение:
    1. Функция принимает строчку которая начинается с цифры, возвращвет такую же строчку.
    2. Функция принимает пустую строчку и выдает обратно пустую строчку.
    3. Функция принимает строчку из пробелов и выдает обратно строчку из пробелов.

Приоритет:
    Средний

Окружение:
	• ОС: Windows 11
	• Версия Python: 3.14.6
	• Версия библиотеки: 9.1.1
